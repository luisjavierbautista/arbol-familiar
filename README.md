# Árbol familiar Bautista Russy

Sitio de consulta del árbol genealógico de la familia: lo documentado, las hipótesis y los pendientes de cada rama.

La página se publica con `noindex` para que no aparezca en buscadores. Los documentos originales y las notas de investigación están en un repositorio privado aparte.

Para actualizar: reemplazar `index.html` y hacer push.
